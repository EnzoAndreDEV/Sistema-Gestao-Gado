# Sistema de Gestão de Gado

Sistema desenvolvido em linguagem C para gerenciamento e controle de animais, permitindo cadastrar, consultar e atualizar informações de cada registro.

## Sobre o projeto

O programa utiliza um menu interativo no terminal para realizar operações de gerenciamento de animais. Cada animal possui um código de identificação, peso, idade e status de disponibilidade para venda.

O projeto foi desenvolvido com foco na aplicação prática de conceitos de programação estruturada.

## Funcionalidades

- Cadastro de animais.
- Listagem de todos os animais cadastrados.
- Consulta por disponibilidade para venda.
- Cálculo da média de peso por status.
- Alteração da disponibilidade para venda.
- Retirada de animais da venda.
- Atualização de peso e idade.
- Listagem de animais fora de venda com peso acima da média dos animais disponíveis.

## Tecnologias e conceitos

- Linguagem C
- Structs
- Vetores
- Ponteiros
- Funções
- Estruturas condicionais
- Estruturas de repetição

## Limitações atuais

- Capacidade máxima de 100 animais.
- Os dados são armazenados em memória durante a execução do programa.
- Não possui armazenamento permanente em banco de dados ou arquivos.

## Objetivo

Aplicar conceitos fundamentais e intermediários da linguagem C na construção de um sistema de gerenciamento com operações organizadas por meio de um menu interativo.
